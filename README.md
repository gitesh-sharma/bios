# BIOS.PAGE.GD

Bitly-style URL shortener + Link-in-Bio platform for `bios.page.gd`.

## Current source package
- Guest URL shortening UI
- Planned custom aliases for accounts
- Link-in-Bio profile architecture
- MySQL schema
- InfinityFree deployment notes

## Stack
PHP 8.x + PDO + MySQL/MariaDB + HTML/CSS/JavaScript.

> GitHub stores the source. PHP/MySQL production runs on InfinityFree/cPanel.

## Important
This package intentionally contains no real database credentials.
